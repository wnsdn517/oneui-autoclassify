# AutoClassify — One UI 홈 앱스 화면 자동 정리

삼성 One UI 홈(앱스 화면)의 앱을 폴더로 자동 정리하는 LSPosed 모듈입니다.

## 기능

- **분류 방식**: 카테고리 · 아이콘 색상 · AI(내 지시대로) · 내 규칙만
- **AI 정리**: "삼성이랑 구글 앱은 따로, 나머지는 카테고리별로. 작은 폴더는 합치고 큰 건 나눠줘"처럼 말로 지시
  - 내 API 키 사용 (Google AI Studio / OpenAI 호환)
  - 검증 추가(선택): AI가 결과를 한 번 더 검사 · 토큰 약 2배
  - 새 앱 설치 시 AI에게 묻기 (쿨다운 · 하루 한도 · 사용 기록)
- **새 앱 바로 분류**: 설치하면 맞는 폴더·페이지로 바로 옮김
- **정렬**: 이름 · 색상(무지개순) · 설치일 · 폴더 크기
- **미리보기 편집기**: 런처처럼 끌어서 옮기기, 폴더 만들기, 페이지 넘기기
- **백업/되돌리기**: 정리 직전 자동 백업
- **앱 안에서 업데이트**: GitHub 릴리즈 확인 · 다운로드 · 설치

## 요구 사항

- Android 15+ (One UI 7+), One UI 홈
- 루팅 + LSPosed (적용 범위: One UI 홈)

## 설치

1. [릴리즈](https://github.com/wnsdn517/oneui-autoclassify/releases)에서 APK 설치
2. LSPosed에서 모듈 켜기 → 범위에 **One UI 홈** 체크
3. One UI 홈 재시작 (또는 재부팅)

## 빌드

```
./gradlew assembleRelease
```
